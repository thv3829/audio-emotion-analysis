# Bidepzai – Audio Emotion Analysis

## Overview
Bidepzai is an experimental machine learning project for audio emotion analysis.

This project explores the use of machine learning models in audio analysis through a simple web interface.

## Technologies
- Python
- Scikit-learn
- Logistic Regression
- TF-IDF
- HTML

## Project Status
This project is a personal experiment and is currently under development.
